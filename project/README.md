# FourView Studio: AI ในเครื่อง

สำหรับภาพเดียว เริ่มด้วย **Hunyuan3D · ภาพเดียวโดยตรง** ระบบจะให้ Qwen3-VL วิเคราะห์ภาพก่อน, ให้ Hunyuan ใช้ภาพต้นฉบับโดยตรงโดยไม่บังคับด้วยมุมด้านข้าง/หลังที่ Wonder3D คาดเดา, แล้วใช้ Qwen ตรวจรูปทรงจริงหลังสร้าง จากการทดสอบกับภาพมังกรตัวอย่าง เส้นทางนี้ได้รูปทรงด้านข้างที่ต่อเนื่องกว่าโหมดมุมสังเคราะห์ แต่ข้อความวิเคราะห์ไม่ได้เปลี่ยนอินพุตของ Hunyuan และส่วนที่ภาพหน้าไม่แสดงยังเป็นการคาดเดา

เลือก **Qwen วิเคราะห์ + AI สร้างมุมเพิ่ม** เมื่อต้องการทดลองภาพรอบตัวที่เติมขึ้นมา โหมดนี้ไม่ใช้รูปทรง/latent เดิม และสุ่ม seed ใหม่ทุกงาน

1. Qwen3-VL 2B Instruct ตรวจมุมมอง จำนวนหาง กายวิภาค และรายละเอียดที่ภาพแสดง
2. Wonder3D สร้างด้านข้างและด้านหลังจากภาพหน้า/เฉียงหน้า Qwen ตรวจว่ามุมเหล่านี้ขัดแย้งกับภาพต้นฉบับหรือไม่ หากผิดชัดเจนจะลองอีก seed หนึ่ง
3. Hunyuan3D-2mv ใช้ภาพหน้า ขวา หลัง ซ้ายเป็น conditioning จริง ผลวิเคราะห์ข้อความไม่ได้ถูกป้อนเป็น prompt เพราะ checkpoint นี้รับภาพ
4. Qwen ตรวจภาพหมุนของ mesh จริงก่อน Paint หากเห็นข้อผิดพลาดใหญ่ด้วยความมั่นใจสูง ระบบหยุดและบอกเหตุผล เก็บภาพตรวจเป็น `shape-review.png` และผลเป็น `shape-review.json` ในโฟลเดอร์ผลงาน
5. Hunyuan3D-Paint สร้างลายผิวตาม geometry แล้วอบ texture 2K/4K โดยปิดการฉายภาพสมมาตรในโหมดช่วยสร้าง

กด **วิเคราะห์ภาพด้วย Qwen3-VL** เพื่ออ่านผลอย่างเดียว หรือ **สร้างภาพ 4 มุมด้วย AI ในเครื่อง** เพื่อดูและเปลี่ยนมุมที่ผิดก่อนสร้างรูปทรง ภาพด้านข้างไม่ได้ถูกสลับกลับซ้ายขวาแล้วอ้างว่าเป็นภาพด้านหน้า

ตัววิเคราะห์ใช้ Ollama แบบ portable ที่ `runtime/local-vision` และน้ำหนักที่ `models/local-vision` ฟังเฉพาะ `127.0.0.1:11435` และตั้ง `OLLAMA_NO_CLOUD=1` ไม่ใช้ API key ไม่ส่งภาพออกนอกเครื่อง ปลดน้ำหนักหลังวิเคราะห์ทุกครั้ง (`keep_alive=0`) และกันการทำงานชนกับงานสร้าง 3D บน GPU 8 GB

ข้อจำกัด: Qwen3-VL 2B และ Wonder3D อาจอ่านหรือคาดเดากายวิภาคผิดได้ Wonder3D สร้างภาพ 256 px; texture 4K ไม่เพิ่มความละเอียดรูปทรงหรือภาพหลายมุม ข้อความวิเคราะห์ของ Qwen ไม่ได้ป้อนเป็น prompt เข้า Hunyuan3D-2mv เพราะ checkpoint นี้รับภาพเป็นเงื่อนไข การตรวจ AI ไม่รับประกันว่าโมเดลจะไม่มีหางซ้ำหรือมีคุณภาพเท่า Tripo หากต้องการความเที่ยงตรงด้านที่ซ่อนอยู่ ให้เพิ่มภาพมุมจริง

TRELLIS ทั้งสองรุ่นและตัวเชื่อม OpenAI ถูกถอดออกแล้ว ผลงานโมเดลเก่ายังคงเก็บใน `outputs` แต่ไม่ใช้ checkpoint/runtime ที่ลบแล้ว

เปิดและหยุดเว็บจาก `Open FourView Studio.cmd` และ `Stop Local AI.cmd` ตามเดิม
